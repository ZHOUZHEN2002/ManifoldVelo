# Changelog

## 1.0.0 — 2026-11-01

- Packaged the frozen manuscript engines for periodic, multipeak periodic and
  open lineage trajectories, preserving their model equations and losses.
- Added portable Python and command-line entry points for paired U/S fitting,
  reference loading and S-only prediction of additional cells.
- Included RNA-based root candidate selection, configuration records, a
  generated-data example, software tests and source provenance.
- Released original contributions under the Academic Research Only license,
  with the upstream TSvelo MIT notice retained.
